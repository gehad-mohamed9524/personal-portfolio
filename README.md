About the Project:

The website introduces my background as a Networking and Information Technology student and shows some of the projects I have worked on in past courses.



Website Pages
    - Home: Introduction
    - About Me: A photo of me, skills, and a short introduction video.
    - Projects: Displays four projects with descriptions, images, and downloadable files.
    - Contact Me: Provides my contact information and an email contact form.



Technologies Used
    - HTML5
    - CSS3
    - CSS Media Queries



Responsive Design

I used fluid design and media queries to make my website work on different screen sizes. The main content uses percentage-based widths so it can adjust to the available screen space.

Viewport ranges:

    - Mobile (600px and below): I chose this range for smaller screens, such as smartphones. The navigation links are displayed vertically, images are resized, and the content padding is reduced to fit the smaller screen.

    - Tablet (601px to 1100px): This range covers tablets and smaller desktop windows. The profile image is adjusted to 60% width, while project images use 70% width.

    - Laptop/Desktop (above 1100px): Larger screens use the main layout, with horizontal navigation and a centered content area. The content has a maximum width of 1100px to prevent it from becoming too wide.



CSS files:

    - style.css — General website styling and desktop layout.
    - mobile.css — Mobile screen adjustments.
    - tablet.css — Tablet screen adjustments.



Linear Gradients:
I used two angled linear gradients in my website:

    - Header: linear-gradient(135deg, #E6D5C3, #D8B4A0) creates a diagonal gradient from beige to peach.

    - Footer: linear-gradient(45deg, #E6D5C3, #D8B4A0) uses the same colors at a different angle.

Both gradients are used across the four website pages.



Color Scheme:

I chose a warm, neutral color scheme because I wanted my portfolio to look simple and consistent, and the dark brown text provides contrast and keeps the content readable.

    - Cream (#F7F1E8): Main website background.
    - Beige (#E6D5C3): Borders and gradients.
    - Peach (#D8B4A0): Header and footer gradients.
    - Dark Brown (#6B4F3A): Text, navigation links, and buttons.
    - Taupe (#A68A7A): Button hover effect.
    - White (#FFFFFF): Main content backgrounds.




Website Features:
    - Four connected HTML pages
    - Responsive layouts for mobile, tablet, and desktop
    - Navigation links between pages
    - Project screenshots and downloadable files
    - Introduction video with playback controls
    - Contact form using email
    - Header and footer gradients
